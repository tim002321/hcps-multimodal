HCPS 采集程序 · 使用说明
==================================

一、启动
  双击 HCPS.exe。
  第一次启动会稍微慢一点（要加载 torch 的 dll），之后正常。

二、换电脑 / 换目录
  直接把整个 HCPS 文件夹复制过去就行，不需要装 Python、不需要装依赖。
  所有路径都跟着 exe 走：
    HCPS.exe          主程序
    _internal\        运行时环境和资源（别删、别拆开）
    config.ini        设备名、阈值等配置（第一次运行自动生成，可改）
    data\             采集到的会话库（按 组别\姓名_时间 归档）
  放在中文目录、U 盘、别的盘符下都能跑，路径里不要有 & % 之类特殊字符。

三、先自检，再上现场
  打开命令行，在本目录执行：

      HCPS.exe --selftest

  结果会打印出来，同时写一份 selftest.log 到本目录。全 [ OK ] 才算就绪，
  有 [FAIL] 看对应行后面的原因。

  自检覆盖：配置文件 / 数据目录可写 / Qt 界面 / 模型文件 / 视觉配置 /
  onnxruntime / 人脸检测 / 哈欠模型 / 四通道融合管线 / 蓝牙后端 /
  串口与 LSL / 摄像头。

  其中「视觉配置」和「人脸检测后端」会明确写出当前跑在 CPU 还是 GPU：
      CPU（onnxruntime）  = 纯 CPU，现场够用（约 17fps 推理）
      GPU CUDA            = 已用上显卡
  换到装了 CUDA 的机器，把 config.ini 的 [vision] device 改成 cuda 即可。

四、现场要核对的两件事
  1. config.ini 的 [bluetooth] device_names：跟当天用的心电贴广播名对齐；
     手环 [bracelet] bracelet_names 同理。
  2. [vision] threshold 只是中性初值，首次使用请用
     tools\vision\calibrate_threshold.py 在本地素材上标定后再改。

五、常见问题
  * 杀毒软件报警：PyInstaller 打的包常被误判，加白名单即可。
  * 提示缺 Qt 平台插件：确认 _internal 目录是完整的，别只拷 exe。
  * 摄像头打不开：先关掉别的占用摄像头的程序（腾讯会议等）。

六、本次录进去的数据
  每一场会话库（data\组别\姓名_时间\时间戳.db）里除了心电、手环、视频，还有两张视觉表：

    vision_frames   每秒一行：有没有脸、张口概率、状态、疲劳档位
    yawn_events     每判定一次哈欠一行：概率、持续秒数

  所以采集结束后，"这一场打了几个哈欠、什么时候开始发困"是可以事后查的，
  不用再靠回看录像数。注意：只有勾着「启用打哈欠检测」采集的场次才有这两张表。

七、帧率
  默认 15fps（config.ini 的 [camera] fps）。哈欠检测本身只有 6~7Hz，15fps 足够，
  而且库的体积比 30fps 小一半。要更流畅的录像再改回 30，代价是库大一倍。

八、哈欠检测看不清嘴时会怎么说
  摄像头装在头顶朝下，被试一低头看仪表，画面里就只剩头发和眼镜。旧版这时候
  仍会给出很高的"张嘴概率"，导致哈欠数字虚高。现在改成：

    · 看得见嘴  → 磁贴显示「正常/张嘴中/打哈欠」+ 张口概率
    · 看不见嘴  → 磁贴显示「低头·嘴不可见」（橙色），画面上人脸框标 HIDDEN
                  这一帧不判哈欠，也不计入张口概率

  下方提示行会写原因：low_conf（关键点看不清）、head_down（低头过度）、
  out_of_frame（嘴出画了）、too_small（人太远）。

  采集结束后，分析页「视觉」块里会多两行：
    嘴可见率(%)  —— 低于 85% 说明机位或距离不合适，该调摄像头
    低头占比(%)  —— 被试低头的时间比例

  三个可调参数在 config.ini 的 [vision] 里（详见 嘴部门控说明.md）：
    kp_conf=0.5           人坐得远、一直报低置信 → 降到 0.35
    mouth_low_ratio=0.95  报低头太频繁 → 调到 1.0（等于不判这条）
    gate_enabled=true     想对照旧行为 → 改 false

  提醒：改成这个口径后，哈欠次数会比以前少，这是把误报去掉的正常结果。
