# 人脸检测两条路，二选一：
#   1) 有 NVIDIA 显卡、想走 GPU：装 ultralytics（会连带装 torch）
#        pip install ultralytics
#      CUDA 版 torch 要单独装（约 2.3GB）：
#        pip install torch==2.5.1+cu121 torchvision==0.20.1+cu121 ^
#            --index-url https://download.pytorch.org/whl/cu121
#   2) 只用 CPU：先下 models/yolov8n-face.onnx，再把 config.ini 的
#      [vision] backend 设成 onnx，不必装 torch。
#
# 模型权重不进版本库，用脚本获取：
#     python tools/vision/fetch_models.py --with-onnx
#
# 本机已验证的组合（Windows 11 / Python 3.12 / RTX 3060 Laptop 6GB）：
#     torch 2.5.1+cu121  torchvision 0.20.1+cu121  ultralytics 8.4.193
#     numpy 1.26.0（不要升到 2.x，pyqtgraph 旧版会不兼容）
#
