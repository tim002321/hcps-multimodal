# 摄像头实时打哈欠检测（vision/）—— 可选，不装就不影响采集与界面
#
# 默认走 onnxruntime（config.ini 的 [vision] backend=ort / device=cpu）：
#     pip install onnxruntime            # 约 15MB，CPU
#   人脸与张嘴都用 ONNX，缺 torch 也能跑。
#
# 想用 GPU（现场那台 NVIDIA 机器）：
#     1) pip install onnxruntime-gpu      # 约 250MB，需 CUDA 12.x + cuDNN 9
#        没有系统 CUDA 时可再装 pip 轮子自带 DLL（合计约 1GB）：
#          pip install nvidia-cudnn-cu12 nvidia-cublas-cu12
#     2) 把 config.ini 的 [vision] device 从 cpu 改成 cuda
#     3) python run_monitor.py --selftest    # 确认「人脸检测后端」显示 GPU CUDA
#   注意：onnxruntime-gpu 与本机已装的 onnxruntime 是同一个 import 名，
#   必须卸载其一（pip uninstall onnxruntime 再装 -gpu）。
#
# 另一条 GPU 路线（本机验证过，但包体大）：ultralytics + CUDA 版 torch
#     pip install torch==2.5.1+cu121 torchvision==0.20.1+cu121 ^
#         --index-url https://download.pytorch.org/whl/cu121
#   torch 后端会自动用 CUDA（vision/face_detector.py 里 device 探测）。
#
# 模型权重不进版本库，用脚本获取（现在默认后端需要 ONNX）：
#     python tools/vision/fetch_models.py --with-onnx
#   yolov8n-face.onnx 12.7MB、yawn_model_80.onnx 9.4MB。
#
# numpy 必须 < 2（pyqtgraph 与部分旧代码不兼容）：
#     装 onnx 等包时如果被升到 2.x，务必改回 pip install "numpy<2"
# ---------------------------------------------------------------------------
